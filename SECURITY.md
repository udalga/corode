# Security

Corode decides things on the server so exploiters can't, so a hole in it could affect every game that uses it. If you find one, please don't post it in a public issue.

**Report it privately:** on GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. Describe what an exploiter could do and how; a small script that shows it helps most.

You'll get an answer as soon as possible, and the fix will come out in a new release. Thank you for keeping Roblox games safe.

For keeping your own game safe with Corode, see the [Security checklist](https://udalga.github.io/corode/reference/security).
